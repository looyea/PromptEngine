# 套餐：教育 · 课程设计（学情目标 → 大纲 → 教案 → 习题评估 → 课件资源 → 试教迭代）

> 用途：引擎模式 B2 的套餐脚本。一次业务对象访谈（一门课/一个单元的设计事项）→ 共享 COURSE_CARD → 交付 6 条按阶段排列的提示词（提示词包本身就是交付物：教师/机构逐条喂给 LLM，产出三维目标书/课程大纲/逐课教案/分层习题与评估/课件资源清单/试教迭代记录）。
> 骨架来源：汇总/教育学习/教学与辅导.md（§4.1 引导式辅导、§4.2 费曼讲解、§4.3 自适应测验、§4.5 教案/学习计划、§4.6 记忆卡片；§2.6 三维目标、§3.5 备课 Outputformat）；R 规则继承 引擎/问卷/教育-学习辅导.md（R1 路线互斥、R2 出题追问、R3 教师备课分支、R6 措辞禁则、R7 学情追踪缺口）。
> 阶段链（ENGINE.md 模式 B 默认链的行业裁剪）：**学情与目标 → 课程大纲 → 逐课教案 → 习题与评估设计 → 课件与资源清单 → 试教反馈迭代**。需求收集=学情目标；产品文档=大纲；设计+实现=教案/习题/课件；测试+上线=试教；运维=学期迭代（末段循环回流）。
> 领域铁律（教学与辅导.md §5）：**引导式（不给答案）与讲解式（直接讲懂）两条路线不可混用于同一条提示词**——课程可按课节混用教学法，但每条教案/互动提示词必须单路线（R1）。
> 硬规格锚：本域没有现成的 游戏Spec01.md 级完备范例，完备度标尺固化为「硬规格锚」一节（位于文末「交付形态」之前）——COURSE_CARD 与 6 条提示词成品逐维度对表走查，缺项不得交付（ENGINE.md 规格饱满模块第 4 条）。

| 交付 | 要哪些交付物？ | **大纲+逐课教案** / 加分层习题 / 加评估设计 / 加课件与资源清单 / 全套 | 全选 → 6 条全跑；只要大纲 → 跑 #1/#2 即止；习题/评估 → #4 触发 R2 追问（难度分层+答案校验） |
| 教学法 | 课堂怎么教？ | **讲授式（费曼 2W2H 讲懂讲透）** / Socratic 引导式（提问让学生自己想出答案，一次一问）/ 项目式（PBL） | 讲授 → §4.2；Socratic → §4.1 五规则+一次一问等待回应；**项目式 → ⚠️ 无专门 PBL 骨架（汇总仅讲解/引导/备课三类）→ §4.5 教案结构+§4.1 引导规则引擎自拼，标 [假设：PBL 流程自拟]**；混用需求 → 按课节分配路线，单条提示词仍单路线（R1） |
| 方法论 | 项目怎么推进、阶段门什么形态？ | **里程碑式（一次性课程设计，推荐）** / Scrum（学期长课迭代）/ 看板（教师个人周备课流）/ 瀑布（教材审定类严格流程） | 决定阶段门形态，见下节；**任何方法论都不豁免 #4 答案校验门与 K12 安全护栏** |

### 方法论与阶段门（ENGINE.md 模式 B 方法论槽位）

- **里程碑式（推荐，一次性设计）**：M0 三维目标定稿 → M1 大纲签核 → M2 教案+习题定稿 → M3 试教修订完成；每个里程碑教师/教研负责人签字才进下一段。
- **Scrum（学期长课）**：每冲刺=一个教学单元（大纲节选+教案+习题+试教复盘），冲刺回顾门=试教反馈消化完毕；未教单元可按学情数据改卡重排。
- **看板（个人备课流）**：每课一张卡沿"目标→教案→习题→课件→试教"流动，适合教师每周滚动备课，无正式签字、以自检门为准。
- **瀑布（教材审定）**：每阶段产物送教研组/审定方书面签核；周期长，适合出版或校本课程立项。

执行注（每条提示词组装时逐项落实）：

- 每条提示词开头携带完整 COURSE_CARD；批量教案/习题=文档交付物，注入 ENGINE.md"文件写入与产物约定"模块（产物清单/PROGRESS 检查点逐课恢复/写入前询问/第三方素材 CREDITS 署名）。
- K12 每条重复注入：内容安全与年龄适配护栏（引擎自补默认段）+"不替学生做作业、收到题目第一条回复禁止直接解出"（§4.1 最高护栏）。
- 措辞禁则词级注入（R6）：不说"听上去有点吓人"类表达、不居高临下、少感叹号少 emoji、回复简短——具体禁则比泛泛"耐心友好"有效（§2.8）。
- 互动式课节提示词插"一次一问、等待回应"协议（§2.2，辅导类与讲解类最大结构差异）；统一保留中文回复尾注（R5）。
- 护栏通用项：不编造、不知道就直说；阶段末给鼓励性小结与下一步建议（§4.3 格式）。

## 分支与变体（同卡换件，访谈时分流）

- **学生自学/家长辅导**：不属本套餐（教师侧课程设计）→ 回 引擎/问卷/教育-学习辅导.md 走 B1；家长场景注入"AI 不替孩子做作业，只引导孩子说出来"护栏（问卷 Q1 联动）。
- **自学计划交付**：客户要的是个人学习计划而非课程 → #2 换 §4.5 自学变体（30 天计划=总目标→每日任务→资源清单→进度评估方法），其余环节按需裁剪。
- **英语口语课节**：→ §4.4 语言练习骨架（严格纠错列原句→改句→正常回应内容→末尾追问一个问题，限 100 词，不写解释性长文，开场先提问）。
- **单词/概念记忆卡**：→ §4.6 骨架（词根/本质分解→谐音或意象联想→一句话记忆故事→例句→卡片），可选 SVG 视觉版与 A 类交叉；一次只处理一个词。
- **换考试体系/学段**：改卡参数 → 习题与难度相关条目（#4 起）重跑；换学段触发 K12 护栏与年龄适配重校准，从 #1 起全链。

## 兼容规则汇总（访谈时当场执行，继承 引擎/问卷/教育-学习辅导.md）

- R1 路线互斥：引导式与讲解式不共存于一条提示词；"既要讲又要练"的课节拆两条提示词串行，不做混合体。
- R2 出题追问：交付含习题 → 当场追加难度分层与答案校验两问；#4 校验门写死；⚠️ 整卷/组卷需求按 §4.3+通用骨架兜底，标 [假设：无命题量规]。
- R3 教师备课分支：本套餐即 R3 的套餐化升级；格式钉死三维目标+教学过程+活动+练习+作业（§3.5）。
- R4 批改类警示：试教反馈涉及作业批改 → ⚠️ 作文批改细则/解题步骤校验无素材（§6），按"指出错误→讲解原因→同类题重练"闭环组装，逐步核对过程而非只看结果，标 [假设：无评分量规]。
- R5 语言尾注：英文指令+中文输出混排素材统一保留中文回复尾注；口语陪练课节走 §4.4（纠错列原句→改句→回应内容→末尾追问，限 100 词）。
- R6 措辞禁则：词级负面清单注入每条提示词，不写成形容词。
- R7 学情追踪缺口：跨会话"记住错题/追踪学情"→ 如实说明无素材，本次交付单会话版；自建方案借鉴 R 类状态文件，另行声明。
- 追加（本套餐）：K12 → 内容安全与年龄适配强制（引擎自补默认段）；项目式 PBL → ⚠️ 无专门骨架，自拼并标 [假设]；⚠️ 学科垂直深度不足（数学校验/物理实验/作文批改）涉及时声明"该细分无专门汇总"（ENGINE.md 兜底规则）。

## 硬规格锚（本域的 游戏Spec01 位：完备交付物应长什么样）

## 交付形态

【COURSE_CARD】+【6 条提示词（编号+用途+使用顺序）】+【阶段门清单（目标确认/大纲签核/答案校验/试教修订）】。两种消费模式：

- **站内引导执行**：引擎按问卷访谈 → 生成卡 → 逐条组装，教师站内执行并贴回产物（教案/习题/试教记录），引擎按阶段门核验放行；批量教案用 PROGRESS 检查点逐课续跑，阶段状态随卡持久化。
- **导出方案给客户内部团队**：按 引擎/方案模板.md（B4）生成完整方案——卡进 §4，提示词包逐条成 P 节点，里程碑 M0-M3 进 §5 门表；[人办] 清单必含：提供知识点清单与学情、教案/大纲签核、习题抽验、**真实试教**、K12 内容安全终审、第三方素材版权确认；§7 运维映射为课程运营节奏（学期迭代：试教与学情数据回流改卡 → 只重跑受影响课节；资源更新与版权复审周期）。缺 §7 不得交付（方案模板使用纪律第 5 条）。

客户复购/改版：改卡 → 只重跑受影响条目（换学段 → #1 起全链；加课时 → #2 起；单课修订 → #3/#4 局部）。教师想"以后自己填学科年级就能跑"→ 升级 B3：本问卷 + §4.5 骨架合并为"教案/课程设计生成器"（问卷 R3 建议路径，照 汇总/提示词方法论/结构化提示词.md §4.2 元提示词骨架）。
