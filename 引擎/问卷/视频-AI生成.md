# 问卷：视频 · AI 生成（Kling / Veo / Seedance / Runway）

> 用途：引擎模式 B1 的访谈脚本。问完→汇总槽位确认→走模式 A 组装目标平台的视频提示词（有叙事意图时先跑剧作层再落语法）。
> 组装原料：汇总/影视视频/视频生成提示词.md（§4.0 平台选型速查、§4.1-4.9 各平台骨架、§4.10 运镜词典、§4.11 修复速查、§2 通用规则 U1-U14）、汇总/影视视频/剧作与分镜.md（§4.1 导演概念卡、§4.3 三层分镜、§4.4 分镜卡→提示词转化、§4.6 情绪外化、§4.7 六项审计）。

## 兼容规则表（选择时当场执行，不只体现在选项上）

- **R1 超 10 秒→拆条计划**：默认 5-10s/条，30s 片=6×5s 拆条剪辑；输出拆条链（剧作确认后按 §4.9：每条自包含+终帧写明与下一条首帧的衔接状态）；例外仅 Kling 3.0 六镜 15s、Seedance 单条多镜/2.5 单段 30s。延长衔接跳变：前段尾删 6 帧+后段头删 1 帧。
- **R2 图生视频只写运动**：不重描述图中已有内容——prompt 只含 运动/镜头/光变化/声音 + `Preserve 剪影·标签文字·服装` 连续性指令，20-40 词短 prompt（§2.2，Kling/Veo/Hunyuan/Seedance 一致）；首帧图质量词（masterpiece 等）不带进视频 prompt（图像吃质量词、视频惩罚它们）。
- **R3 Sora 停服处理**：Sora 2 已于 2026-09-24 停服，不作为可执行平台推荐；客户要"Sora 式写法"时说明其 Shot List/Beats 结构可迁移到 Kling 3.0/Seedance 多镜头（§4.5 保留作写法参考）。
- **R4 禁用空词强制替换**：cinematic / epic / stunning / masterpiece / beautiful lighting / dynamic camera / "he is sad" 一律不出现，逐个替换为具体物理事实（光源+方向+色温、身体线索、动作后果）——依据 视频 §2.1 禁词表 + 剧作 §2.2；组装前跑六项剧作审计（§4.7）与三细节检查。
- **R5 系列连续性**：模型无跨次记忆——每条 prompt **逐字重复完整身份块**（U7）与光照常量（"Lighting constant: …"），道具/服装同部件同描述；参考角色逐个绑定声明"取什么/忽略什么"（U13），禁止集体指代。
- **R6 时码口径按平台**：Kling 3.0 写 `Shot n (0-3s)` + 相邻镜景别角度必不同（否则合并成一镜）；Seedance 写"镜头1/2/3"按事件顺序、**不强制秒数**；分镜设计层可带 timecode，落到 Seedance prompt 层去掉（剧作 §5 两层口径分离）。
- **R7 对白/声音语法三派不混用**：Veo `Says: 角色 says, in a {{语气}} voice: "…"`（引导动词+双引号）+ `Audio:/SFX:()`；Kling 3.0 `[Character A, 音色]: "…"` + 台词前绑唯一视觉动作(P2) + 句间衔接词 Immediately/Then(P4)；Seedance 中文符号 `{台词}` `(音乐)` `<音效>` `【字幕】`，外语标语种；多音字读错换同音常用字（仅缓解）⚠️。
- **R8 负向语法三派换算**：Kling 专用负向栏写实体词（"watermark" 而非 "no watermark"，栏太长削弱运动）；Veo/Seedance 2.5 正文 "No subtitles" 可靠；Seedance 1.x 需全部反转为正向措辞。矛盾约束拦截：8mm胶片感×4K超清、slow motion×高速动作、film grain×ultra sharp、>2 个艺术家风格（§2.4）。
- **R9 多镜头先过剧作层**：task=多镜短片 → 先生成导演概念卡+五锚点+三层分镜表（剧作 §4.1-4.3），客户确认后再按 §4.4 字段映射逐镜转平台提示词；每镜至少干一件事（改情绪/推动作/增压力），命名不出场景五要素就不进分镜。
- **R10 平台容量与画质权衡**：Kling 2.5 Turbo ≤3-4 元素、2.6 Pro 5-7；Seedance 参考人物 ≤4、素材 4-5 个勿用满上限、角色锚用大头照+全身照勿多视图；Elements/参考开启会降画质，一次性片段用 in-prompt 标签。
- **R11 时长两个口径**：交付时必须分开写"单条生成时长"与"成片时长"——素材对 Veo（4/6/8s vs 链式延长至 60s）、Kling（15s vs 智能分镜 2 分钟）记载不一，属单条 vs 延长口径差异而非矛盾（§5）；30s 成片默认走 R1 拆条而非要求单条 30s（Seedance 2.5 单段 30s 除外）。
- **R12 优先级声明（prompt 过长）**：信息超载时按压缩顺序砍——先砍哲学/形容词/导演引用，保 角色连续性 > 动作 > 时码 > 光 > 镜头 > 剪辑语法 > 声音（§4.11 末行、U14）；并可显式写入"必保主体 > 必保镜头 > 可自由发挥的过渡 > 强制终帧"。
- **R13 静帧→视频两段流水线**：客户对构图要求极精（特定姿势/版式）而文生视频控不住 → 先按 绘画-出图.md 问卷产关键帧图（构图与分镜、剧作与分镜 §4.5 animatic 路线：静帧只 prompt 运动的物理后果），锁定后作图生视频首帧（R2 短 prompt），实现"静帧锁构图 → 视频赋运动"。
- **R14 已知失败模式预注入**：按 §4.11 速查预防性写条款——多镜塌一镜加 `Cut to.`/`must be multi-shot with visible hard cuts`；角色换脸重复身份块；双胞胎加"禁止外形着装完全一致人物"；静态场景乱漂加 `locked static frame, camera fixed, no movement`；手融/多指在正向写 `anatomically correct hands`（Veo/Seedance）而非只靠负向；快速动作形变改"慢动作生成+后期加速"。
- **⚠️ 素材缺口如实告知**：音乐/音效设计层素材薄（配乐向需求跨音乐类组装）；Runway/Pika/Luma 实测样本少、Aleph 与 Pikaframes 玩法缺实测反馈；tier=unverified-3rd-party 例只作灵感不作语法依据；生成前核对平台当前文档（语法取证日 2026-11-19）。署名义务：方法论改写须注明 Serge Shima / smixs/visual-skills（CC-BY-4.0）。

## 终态核对（念给客户确认后再组装）

槽位汇总表：platform / task / duration_ratio（单条与成片两值）/ subject_action / camera / mood_scene / audio_dialogue / continuity / references / positioning + `[假设]` 项 + **剧作审计结论**（六项是否过）；客户确认后组装，改选则回跳对应题并重跑 R4 空词与 R8 矛盾检查。

## 终态 → 组装（交回模式 A 第 3-7 步）

输出三部分：
1. **提示词正文**：单条→§4.1 通用骨架（主体/动作/场景/镜头/光影/风格/声音/时长画幅/连续性/约束 十段序，主体动作前置 U2、风格放尾）或对应平台骨架（Kling §4.2/4.3、Veo §4.4、Seedance §4.6、Runway §4.7、图生视频 §4.8）；多镜→先剧作卡（导演概念卡 §4.1 + 五锚点 + 三层分镜表 §4.3，输出格式 C 分镜表）再按 §4.4 字段映射逐镜转提示词；超时长→§4.9 拆条链（含剪辑注）。
2. **参数与设置备注**：平台版本、单条时长/画幅、generate_audio 开关（要干净音轨就关，"no music"不可靠）、cfg_scale 建议（Kling 0.3-0.4 创意 / 0.7-1.0 严格）、Kling API 与 Seedance 素材数量上限。
3. **失败预案**：附 §4.11 修复速查中与本条相关的 3-5 行 + 重抽时"先诊断再改词/调参/修图，不盲目重掷"提示。
