# 平台档案：海外建站与支付（Shopify/Webflow/Wix + Stripe/PayPal）

> ⚠️ **引擎自补知识（非收集素材），关键约束以官方文档为准，使用前核实。** 库内无 SaaS 建站与海外支付汇总，本档案平台规则均为引擎自补；可引用的只有套餐/引擎的结构范式与通用安全纪律（逐条标注）。价格、费率、导出政策、支持地区列表均为高易变项。
> 用途：问卷选项背后的约束层。被引用方：引擎/套餐/商城开发.md 技术组（SaaS 分支）与支付组（Stripe/PayPal 选项展开）；B4 方案 [人办] 清单供料（引擎/方案模板.md §3）。

## 1. 定位与适用场景

面向海外客户、要免 ICP 备案快速上线、预算按月付而非一次性开发、或团队无技术运维能力时选它：电商选 Shopify，品牌官网/内容站选 Webflow/Wix。需要深度定制业务逻辑（复杂促销/多商家分账）、数据完全自主、或主要用户在中国大陆（访问速度与本地支付不友好）时不选——转自研路线（Next.js 或 LAMP-PHP 档案）。

## 2. 硬约束清单

| # | 约束 | 影响 | 来源 |
|---|---|---|---|
| S1 | 平台锁定与导出限制：Shopify 商品/订单可 CSV 导出但主题与业务逻辑不可迁移；Webflow 静态代码导出需付费档且 CMS 内容不随导出；Wix 基本不可导出 | "先 SaaS 后自研"的迁移成本要预先告知：数据可带走，站点逻辑要重做 | 官方文档常识（自补，导出政策易变） |
| S2 | 持续月费成本：平台订阅 + 付费主题/应用（app）逐个累加；Shopify 用第三方支付网关另收交易附加费 | 报价必须算 12 个月 TCO 而非"开发费"；与自研一次性成本对比进 DECISIONS | 官方文档常识（自补，费率以官方现行页为准） |
| S3 | 主题/模板语法各不相同：Shopify 用 Liquid 模板 + JSON 模板配置；Webflow 是可视化设计器+自定义代码嵌入位；Wix 用 Velo(JS) | "平台决定语法"——定制提示词必须按所选平台生成，HTML/React 代码不能直接注入（同 引擎/问卷/绘画-出图.md R1 的跨平台语法纪律） | 官方文档常识（自补）；"平台决定语法"范式出处：引擎/问卷/绘画-出图.md R1 |
| S4 | Stripe 开户需受支持国家/地区的主体（中国大陆主体不能直接开户）；需海外公司/合规通道，且开户审核有拒批风险 | 支付可行性是**前置阻塞项**，不是技术集成问题；无主体则整条路线要重选 | 官方文档常识（自补，支持地区列表须核实） |
| S5 | PayPal 商业账户 + 提现通道（结汇到国内账户有额度与合规路径问题）；风控冻结资金风险高于本地支付 | 收款主体与资金回流路径进 [人办]；提示客户预留风控申诉周期 | 官方文档常识（自补） |
| S6 | 税务：欧盟 VAT（含 OSS 申报）、美国 sales tax 按州 nexus 判定；平台税务工具只是计算辅助，申报责任在卖家 | 方案必须含"税务登记咨询"节点；引擎不得给出具体税率结论（免责） | 官方文档常识（自补；免责纪律范式同 ENGINE.md 第 5 步法律/金融条款） |
| S7 | PCI 合规大头由平台/托管收银台承担（用 Shopify Payments/Stripe Checkout 托管页则商户不碰卡号）；但 API 密钥管理在客户：secret key 绝不进前端/仓库 | 集成方式默认选托管收银台而非自建卡表单；密钥纪律强制注入 | 官方文档常识（自补）；"不提交密钥"纪律出处：汇总/软件开发/Agent系统提示词.md §3 样本E |
| S8 | checkout 深度定制受限：Shopify 结算页仅 Plus 档可有限扩展；促销/订阅等复杂玩法依赖 app，app 之间可能冲突 | 商城问卷 R4 促销叠加规则在 SaaS 端要先核对 app 能力，不能承诺任意定制 | 官方文档常识（自补，档位政策易变）；R4 出处：引擎/套餐/商城开发.md |
| S9 | 免中国大陆备案，但大陆访问速度不保证、微信/支付宝生态接入弱；面向大陆推广的站点不适用 | "免备案"是卖点也是边界，问卷要问清目标市场再推荐 | 官方文档常识（自补） |
| S10 | 与自研路线对比进 DECISIONS（≥2 方案）：SaaS=上线快/免运维/月费+锁定 vs 自研=完全定制/数据自主/开发+运维成本高 | 客户不懂时给推荐并记录理由 | 范式出处：ENGINE.md B4 第 4 条、引擎/套餐/商城开发.md 技术组 DECISIONS 条款；对比内容为自补 |

## 3. 对问卷槽位的影响（编号建议）

- **S-R1 市场前置问**：选 SaaS 建站 → 先问"客户在哪些国家/地区？"含中国大陆为主 → 当场提示 S9 边界，建议回技术组重选。
- **S-R2 主体拦截**：支付组选 Stripe → 追加"是否已有海外公司主体或合规收款通道？"没有 → S4 阻塞告警，[人办] 前置或改 PayPal/回微信支付路线；选 PayPal → 追加提现路径确认（S5）。
- **S-R3 语境转写**：技术组选 SaaS → 商城套餐阶段链裁剪：第 2 条（数据库设计）删除、第 3 条（API 设计）改为"平台数据模型+app 选型清单"、第 5 条（前台）改为"主题配置+{{Liquid/嵌入代码/Velo}}定制"；提示词全文用"配置+定制"措辞（见片段 A）。
- **S-R4 促销核对**：R4 促销叠加问题保留，但答案须映射到具体 app 能力核对（S8），无法实现的玩法当场降级或标 [假设]。
- **S-R5 成本核对**：终态核对时追加 12 个月 TCO 估算表（订阅+app+交易费），与自研报价并排进 DECISIONS（S2/S10）。

## 5. [人办]与合规事项（进方案 §3 自办清单）

- 平台账号注册、订阅档位购买与续费责任归属（谁的信用卡、谁收账单）。
- 海外收款主体：海外公司注册或合规收款通道选择（Stripe 前置，S4）；PayPal 商业账户认证与提现/结汇路径确认。
- 税务登记咨询：目标市场 VAT/sales tax 义务判定与申报，交专业会计（S6，引擎与 LLM 均不出税务结论）。
- 域名购买与 DNS 指向平台；企业邮箱与平台通知发件域验证。
- 密钥保管制度：API secret/webhook 签名密钥的存放与交接（S7），人员变动时轮换。
- 目标市场消费者合规：退换货政策页、隐私政策（GDPR/CCPA 视市场）——法务免责注入，人审后发布。

## 6. 缺口与待核实

- **全部价格/费率/档位/导出政策未标具体数值**——本档案刻意不写死金额，使用前对照 Shopify/Webflow/Wix/Stripe/PayPal 官方定价页核实（S1/S2/S8 高易变）。
- Stripe 受支持国家/地区列表、中国大陆主体的合规通道方案变动频繁，S4 只给结构性结论，具体通道须客户咨询专业服务商。
- 库内零 SaaS 建站素材：Liquid/Velo 语法细节无词表级支撑（对比绘画域有词表），定制片段生成时声明自补并建议小步验证。
- 未覆盖：WooCommerce（属 LAMP-PHP 档案）、自研独立站+Stripe 直连路线、多币种/多语言站深度方案、Stripe 订阅计费（可与商城 R2 联动但细则待补）。
