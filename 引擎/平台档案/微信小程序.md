# 平台档案：微信小程序

> ⚠️ **引擎自补知识（非收集素材），关键约束以官方文档为准，使用前核实。** 本库无微信小程序专门汇总，平台规则均为引擎自补；仅问卷联动结构与通用开发纪律有库内出处（逐条标注）。
> 用途：问卷选项背后的约束层。被 引用方：引擎/套餐/商城开发.md（用户/支付/技术三组的 R5 展开版）、引擎/问卷/编程-通用开发.md Q3 stack 槽位；模式 B4 方案的 [人办] 清单供料（引擎/方案模板.md §3）。

## 1. 定位与适用场景

客户主战场在微信生态（私域、社群、扫码复购）、要"用完即走"的轻应用时选它。需要搜索引擎流量、复杂长表单后台、海外用户、或不愿受腾讯审核节奏约束时不选——改选 Web/App。电商场景它是商城套餐技术组三选项之一，选它即触发 R5 三处联动改写（引擎/套餐/商城开发.md）。

## 3. 对问卷槽位的影响（R5 展开，编号建议）

商城套餐选"微信小程序"后，R5 展开为以下子规则，访谈时当场执行（ENGINE.md B1 纪律）：

- **R5a 登录锁定**：用户组"登录与会员"锁死为微信授权，删除手机验证码/邮箱选项；追加一问"是否需要绑定手机号？"（需企业认证+付费接口，讲清成本再让客户拍板）。
- **R5b 支付锁定**：支付组锁死微信支付，其余渠道当场提示不可选；追加一问"是否已有微信支付商户号与营业执照？"——没有则进 [人办] 清单并标注为上线阻塞项。
- **R5c 技术栈改写**：技术组前端语境换 WXML/WXSS；追加选型题"原生小程序 vs 跨端框架（uni-app/Taro）"，比较 ≥2 方案写进 DECISIONS（范式出自 ENGINE.md B4 第 4 条；⚠️ 跨端框架库内无素材，属自补建议）。
- **R5d 包体与分包**：追加"页面规模预估"一问；超主包限制→提示词包第 5 条（前台）注入分包结构约定。
- **R5e 类目与资质**：与 R6 合流——先问经营类目，再按类目列资质清单；医疗/食品类强制法务免责注入。
- **R5f 域名与备案**：追加"后端域名是否已备案+HTTPS？"未备案→[人办] 前置项，写入上下文卡 [假设] 区。
- 对 编程-通用开发.md：Q3 stack 槽填"微信小程序（原生/跨端框架）"，Q10 安全约束自动追加 W7 内容安全条款。

## 4. 可挂载提示词片段

**片段 A：技术栈声明块**（注入商城提示词包 #4/#5 及单条开发提示词的 Rules）

```markdown
目标平台为微信小程序：前端只用 WXML/WXSS/JS/JSON，禁止生成 HTML 标签、
DOM/window/document 操作与浏览器专用 API。网络请求统一 wx.request 封装，
域名走合法域名配置。登录基于 wx.login+后端 code2Session，禁止自造账号密码体系。
支付只对接微信支付（JSAPI），金额与回调验签在服务端完成。
不假设任何 npm 包可用，先查 project.config.json 与既有依赖（纪律参照 汇总/软件开发/编码规约.md §2.6）。
```

**片段 B：审核避坑块**（注入需求 spec 与上线检查单）

```markdown
设计与实现须满足小程序审核：1) 功能与所选类目一致，资质类目先证后上；
2) 所有 UGC 入口接内容安全检测并留人工复审后台；3) 不出现诱导分享/关注文案、
外部下载引导；4) iOS 端不出现虚拟商品购买入口；5) 提供隐私政策与用户信息
授权说明。提审前自查以上五项，任何一项不满足即阻塞发布（BLOCKING）。
```

**片段 C：包体与分包约定块**（注入前台/后台页面提示词）

```markdown
主包只放 tabBar 页面与公共组件，控制在官方主包上限内（数值以现行文档为准，
生成前核实）；商品详情、营销活动按业务拆分包并配置按需加载；图片/视频一律
走 CDN URL，禁止打进代码包。新增页面前先声明归属分包。
```

## 5. [人办]与合规事项（进方案 §3 自办清单）

- 小程序账号注册 + 企业主体微信认证（年费；个人主体功能受限，收款类必须企业）。
- 微信支付商户号申请：营业执照、法人信息、对公账户打款验证；与小程序 appid 绑定。
- 经营类目资质证件办理（食品经营许可、医疗器械备案等，按 R5e 清单）。
- 后端域名购买 + ICP 备案 + HTTPS 证书（W5 前置，周期以周计，须最早启动）。
- 小程序后台配置：合法域名、隐私保护指引、内容安全接口开通。
- 免责提示：支付资质与备付金合规需另行确认（引擎/套餐/商城开发.md 支付组既有免责条款）。

## 6. 缺口与待核实

- 包体上限、手机号接口计费、虚拟支付政策、用户信息接口均为**高易变项**，本档案数值与接口名使用前必须对照微信官方现行文档核实。
- 跨端框架（uni-app/Taro）与微信云开发路线库内零素材，本档案仅原生路线展开；客户选跨端时另行声明自补。
- 小程序插件、直播组件、交易组件（视频号联动）未覆盖。
- 审核实操尺度（驳回话术、加急通道）无收集素材，片段 B 为常识性避坑清单，不保证过审。
