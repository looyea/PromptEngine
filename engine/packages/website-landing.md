# 套餐：官网与落地页（单页/少页站点轻量版）

> 用途：引擎模式 B2 的套餐脚本，面向"给我做个官网/产品落地页"的小团队与个人。一次业务对象访谈（一个站点）→ 共享上下文卡 SITE_CARD → 交付 6+1 条按阶段排列的提示词（提示词包即最终交付物：客户逐条喂给编码 agent/LLM，产出可上线的站点）。
> 定位边界：本套餐是 引擎/套餐/商城开发.md 的**轻量版**——单页落地页/少页官网/作品集，不含商品/SKU/订单/支付/后台。客户要完整电商→当场转 商城开发.md（B2）；只要一篇落地页**文案**不要站点→走 引擎/问卷/营销-文案.md（B1）。
> 骨架来源：汇总/B2B商业/营销文案.md（§4.2 落地页 brief/指令分离与 9 段结构、§4.5 SEO、§4.6 去 AI 味终检、§5 真实性约束、§6 缺口）；汇总/软件开发/编码规约.md（§4 规约骨架与文件写入约定）；汇总/软件开发/Spec驱动开发.md（§4 specify→plan→tasks→implement 链，轻量裁剪）；问卷 R 规则继承：引擎/问卷/营销-文案.md、引擎/问卷/编程-通用开发.md。
> 完备度标尺：本域的 游戏Spec01.md 位＝文末「硬规格锚」节（依 ENGINE.md 规格饱满模块 v0.8 增设）——6+1 条产物的终稿逐维度对照该表走查，只有原则没有数值/清单/可判是·否条目的节视为壳节回炉。
> 阶段链裁剪自 引擎/ENGINE.md 模式 B 默认链（需求收集→产品/业务文档→设计→实现→测试→上线→运维）：需求与文案 brief→信息架构与页面设计→视觉风格提示→前端实现→内容与 SEO→上线检查→（可选）迭代。

## 阶段链总览（默认链的行业裁剪）

```
需求与文案 brief(#1) → 信息架构与页面设计(#2，线框文字描述)
→ 视觉风格提示(#3，可转绘画问卷出图) → 前端实现(#4)
→ 内容与 SEO(#5) → 上线检查(#6) → [可选] 迭代(#7，数据回流改卡)
```

- 对应 ENGINE.md 模式 B 默认链：需求收集+业务文档=#1，设计=#2/#3，实现=#4，测试=#4/#5 内嵌证据门，上线=#6，运维=#7 与卡内运维节奏交代。
- 阶段门形态随方法论槽位：看板（推荐）=每条目过门即流动，适合个人/小团队；里程碑式=客户逐阶段签字（外包协作时）；Scrum=多页站持续迭代每冲刺回顾；瀑布=一次交付不回头（仅极简单页）。
- 阶段状态随 SITE_CARD 持久化：每过一门登记版本与日期，中断后读卡从下一未完成阶段恢复；#3 缺图不阻塞 #4（占位图先行，图到后只替换素材）。

```
类型=单页落地页 | 目的=获客留资 | 技术=纯静态 HTML | 语言=中文单语
```

⚠️ 三项**不许默认**：产品一句话、唯一转化目标（缺了无法保证 Message Match 与 1:1 注意力比，继承营销-文案.md R13）、真实素材清单（缺项必须 `[待补]` 登记，禁虚构）；托管地域必须问明（决定是否触发 R2 备案）。其余按上表兜底并念回确认。

## 阶段门失败回环（通过才进下一段）

- #1 brief 缺必填槽位 → 回访谈补问，不许模型代填虚构（营销-文案.md R4）；社会证明无真实素材→`[待补]` 占位放行，但 #5 上线前必须补齐或删该段。
- #2 线框出现第二主 CTA / 导航外链 → 违反 1:1 注意力比，当场打回重排；多页站只约束转化页。
- #3 风格与品牌语气冲突（如 B2B 专业克制 × 促销大红大字）→ 语义一致性检查不过（ENGINE.md 第 6 步），回卡核对语气字段再重出。
- #4 主路径走不通 / 表单数据未到达留资通道 → 不过门；修 bug 按"期望-实际-环境"三要素排障（编程-通用开发.md Q1 联动），测试失败先怀疑被测代码。
- #5 去 AI 味终检不过 / 禁词命中 / 多语言出现通用 fallback → 只重跑 #5 对应语言版本，不动代码。
- #6 任一检查项红 → 停在线上之前：技术项回 #4/#5，[人办] 项（备案/隐私政策/域名）点名催办，不带病上线。
- #7 无数据硬归因 → 报"未评估"并列缺哪张表（诚实裁决，通用自 汇总/游戏/工作流与验收.md）；改动建议先改卡再重跑受影响条目。

## 客户画像速查（访谈前给客户的三个典型档）

- 个人作品集：单页、品牌展示目的、已有作品图 → 砍表单与 R1，CTA="联系我"；#5 SEO 降为基本 meta，#7 可选不启用。
- 小团队获客落地页：单页、留资表单、投信息流广告 → 全链启用，R8 Message Match 必问上游广告口径；国内托管则 R2 备案先行。
- 初创公司多页官网：3-5 页、中英双语、Next.js → #2 加站点地图，R3 逐语言差异化跑两遍 #5；复杂度告警：博客/招聘等栏目建议二期。

## 兼容规则汇总（访谈时当场执行）

- R1 留资表单→隐私与数据最小化：任何收集个人数据的入口→追加隐私政策页提示词块 + 字段最小化论证（只收跟进必需项）；**隐私政策定稿、表单服务账号注册为 [人办] 事项**进自办清单；涉敏感行业另提示数据合规人审。
- R2 国内托管→ICP 备案：托管地域=国内→备案进自办清单 [人办]（前置条件：域名实名+主机商幕布流程，周期数周），#6 检查单含"备案号悬挂页脚"；未备案不得解析上线。
- R3 多语言→逐语言真实差异化：每语言独立关键词研究+文案重写+社会证明本地化，**禁止机翻通用 fallback**；语言数≥3→复杂度告警，建议一期先做主语言。
- R4 技术路线约束：按 引擎/平台档案/ 对应档案执行——建站工具→海外建站与支付.md（只产内容块/配置说明，能力边界标 `[假设]` 待官方文档核对）；LAMP→LAMP-PHP.md（主机前置问触发共享主机降级链）；纯静态↔Next.js↔建站工具选型比较≥2 方案进 DECISIONS；客户不懂→给推荐并写进卡。
- R5 敏感行业合规注入（继承营销-文案.md R2）：医疗/金融/教育/食品→绝对化用语禁词表（"最/第一/100%/根治/稳赚"类）+ 行业免责句；⚠️ 本库无成品文案合规审查提示词（营销文案.md §6），注入的是预防性禁则，**不替代人工合规审**，交付时明示。
- R6 真实性硬条款（默认注入，不问客户）：社会证明/数字成果/奖项只准用客户提供的真实素材，缺→`[待补]` 占位；素材宣称数字（"engagement 300%+"类）是风格锚不是指标，Success Metrics 只作目标槽并提示客户校准（营销文案.md §5）。
