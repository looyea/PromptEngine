# 问卷：办公 · 总结翻译邮件

> 用途：引擎模式 B1 的访谈脚本。问完→汇总槽位确认→走模式 A 组装文本加工类提示词（压缩=总结、转换=翻译、投递=邮件，兼及会议纪要/汇报等职场文体）。
> 组装原料：汇总/办公效率/总结翻译邮件.md（§4.1 分层总结、§4.2 多文档流水线、§4.3 翻译档位协议、§4.4 信达雅三层、§4.5 润色、§4.6 商务邮件）、汇总/办公效率/职场文档.md（§4.1 周报四段+150 字限额、§4.3 会议纪要八要素、§4.4 公文文种参数化、§4.7 PPT 大纲）。
> 领域铁律（总结翻译邮件 §2.1、职场文档 §5）：**总结与纪要=抽取而非创作**，"不扩写/不编造/数据校验"的忠实性约束不可被风格模块覆盖——这是职场文档与文案创作的根本分界。

## 兼容规则表（选择时当场执行，不只体现在选项上）

- **R1 摘要忠实原文铁律**：凡 Q1=总结/纪要/周报 → Rules 强制注入"只抽取不创作、不添加原文没有的信息、缺失处标『未提及/待补』占位"（§4.1 约束、职场文档 §2.2"不扩写仅整理、病句微调、每步后数据校验"）。客户想"加点亮点"→ 引导改用润色（§4.5）或语言包装骨架（职场文档 §4.2），并加护栏"不得改变事实与责任归属、不得把未完成说成已完成"；李继刚原版含讽刺意图，默认剔除"避重就轻"步骤（职场文档 §5）。
- **R2 翻译术语表追问**：Q1=翻译且文本含专业词 → 当场追问：有既成术语表吗？有→注入 §4.3 `术语表={{}}` 槽并锁定；无→提示"术语一致性与译后质检（回译校验）无素材（§6），建议首轮先产出术语对照表，客户确认后固定复用"。同时确认前缀协议（phrase:=按短语、normal:=孤立词、多词条 | 分隔，§2.5）与敏感内容策略——素材的"以 x 替代"是译者中立策略，通用场景改为可配置项（§5 风险注记）。
- **R3 多文档流水线**：Q2=多篇文档 → 换 §4.2 三阶段骨架：逐篇接收编号 @1..@N（每篇回"已收讫+一句话主旨"）→ 横向共性/差异综述 → 合并摘要+交叉校验（指出篇间矛盾、注明依据哪篇）。
- **R4 纪要八要素**：Q1=会议纪要 → 按职场文档 §4.3 钉死八要素（主题/日期时间/参会人/记录者/议程/主要讨论【问题·提议·观点】/决定与行动计划【负责人+期限】/下一步打算），可选行动项表格（事项|负责人|期限|状态）；每要素整理后自查与原文一致。
- **R5 邮件缺口如实标注**：日常商务邮件（请假/催办/道歉/跨部门协调）素材几乎为零（§6），§4.6 骨架为归纳自拟——组装时声明；不虚构承诺、敏感信息留占位符；偏营销味需求→提示归 B 类并加"开信率话术不得滑向标题党"真实性约束（§总结翻译邮件 5）。
- **R6 公文语料约束**：Q1=公文 → §职场文档 4.4 文种参数化：格式（标题"关于…的…"/主送/依据/事项分条/结尾用语/落款日期）+ 语料来源纪律（引用政策优先权威来源；不在知识库的信息明确说不知道，**不编造文号与数据**）。
- **R7 周报双版本分界**：Q1=周报 → 默认严肃版骨架（四段+每项≤150 字+输入没有的量化结果留 `[待补]`）；"包装版"（真心话→汇报腔）仅作语体转换工具并向客户说明其讽刺作品出身（职场文档 §5）。

## 默认速配（客户说"都用默认"时的终态）

```
task=摘要总结 | input_form=一段贴入文本 | language=英↔中 | register=信达雅
length=摘要100-300字+大纲 | audience=决策者 | purity=只输出结果
```

默认档同样要念给客户确认；task 落到纪要/周报/邮件时没有"安全默认"——R4/R5/R7 必须当场过一遍再组装。

## 终态 → 组装（交回模式 A 第 3-7 步）

终态核对槽位汇总表：

```
task={{摘要总结}} input_form={{多篇文档}} language={{英→中}} register={{信达雅}}
length={{摘要200字+大纲}} audience={{决策者}} purity={{只输出结果}}
[假设] 条目：{{逐条列出}}
```

1. **选骨架**：总结→§4.1；多文档→§4.2；翻译→§4.3（展示/教学加 §4.4）；润色→§4.5；邮件→§4.6；纪要→职场文档 §4.3；周报→§4.1(职场)；公文→§4.4；PPT→§4.7。
2. **填参数**：字数限额、受众、语域档、术语表、协议前缀、精度档全部进 `{{}}`；CoT 触发语（"一步一步思考"，§3.1）可留给总结类。
3. **质检加项**：逐条核对 R1 忠实性未被风格模块覆盖；数字与专名与原文一致；缺信息处是占位而非编造。

## 交付为"生成器"时（B3）

客户每周固定跑同类任务（纪要/周报/双语简报）→ 本问卷 + 汇总/提示词方法论/结构化提示词.md §4.2 元提示词骨架合并为"办公文本加工生成器"，八要素、150 字限额、忠实性铁律做成不可删改的固定前缀，仅任务参数开放复用。
