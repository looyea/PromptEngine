# 问卷：写作 · 自媒体内容（文章 / 小红书 / 公众号 / 口播 / 小说章节）

> 用途：引擎模式 B1 的访谈脚本。问完→汇总槽位确认→走模式 A 组装"平台 × 文体 × 风格"的写作提示词。
> 组装原料：汇总/写作内容创作/文案与自媒体.md（§4.1 小红书骨架、§4.2 标题法则库、§4.3 品牌短文案、§4.4 公众号长文、§4.5 改写润色）、汇总/写作内容创作/小说与剧本.md（§4.1 小说分环节骨架、§4.2 短剧分镜脚本、§4.3 微小说、§4.4 诗歌）、汇总/B2B商业/营销文案.md（§4.6 去 AI 味终检，带货路由见 §4.1-4.4）。

## 兼容规则表（选择时当场执行，不只体现在选项上）

- **R1 平台 × 体裁决定结构模板**：小红书→§4.1 四件套骨架（5 标题先行→正文每段 emoji→文末抽 3-6 个 SEO 词生成 #标签，只输出格式内内容）；公众号/长文→§4.4（钩子开头→深刻提问引题→观点+案例数据≥2→社会现象→升华→金句收尾→开放问题）；品牌短文案→§4.3；改写→§4.5。不存在"一套通用排版"，模板在选定后当场绑定。
- **R2 小说类→路由**：genre=小说章节/短篇 → 本问卷平台规则不适用，改按 小说与剧本.md §4.1 分环节组装（梗概→章节大纲→正文→续写，每章末附"新增伏笔清单"防吃书）；短剧脚本→§4.2 分镜表硬格式；⚠️ 网文工业流程（黄金三章/爽点节奏/日更断章）素材缺失，只有传统文学腔条目；长篇一致性工程（人物卡/世界观圣经）无现成素材，引擎自建槽位并向客户说明。
- **R3 诗歌/歌词缺口如实**：genre=诗歌 → 用小说 §4.4（主题+形式+行数+意象目标，出 N 首备选）；要歌词 → ⚠️ 素材库无系统的押韵/韵位/旋律结构方法论，只做"主题→段落占位"级处理；完整歌词写作建议转 音乐-写歌.md 的歌词槽或客户自写（与 音乐 问卷 R5 同源）。
- **R4 带货/转化属性→跨问卷路由**：内容目的是卖货/引流/落地页/EDM（出现产品链接、促销活动、转化目标）→ 转 营销-文案.md 问卷组装，本问卷只负责"内容壳"；交叉引用不重复（文案 §6：营销战略、SEO、电邮归 B 类）。
- **R5 标题党护栏**：选"极端对立(二极管)"→自动追加两条：不得虚构事实、不得恐吓过度（咪蒙法则库原例句含低俗擦边，入库只保留法则结构、例句替换，文案 §5）；"低调"→只用数字/悬念/共情类温和法则，每条标题标注【法则-子策略】+心理触发点分析。
- **R6 口播稿特化**：短句、口语、简单中文、连接词与语气词，避免模板腔与重复句式（ChatGPT-Shortcut #204 式）；与前 3 秒钩子条款绑定（短剧 §4.2：开场必冲突/悬念/利益点，结尾留互动引导）。
- **R7 改写式最小指令**：Q2=已有文本 → 只输出改写结果不解释、保持原意；风格清单按目标体裁复用 §4.1/§4.4 的规则项。
- **R8 配图提示跨问卷交付**：要封面/插图 → 生成配图 brief（画面主体+构图+色彩，小红书封面默认 3:4 竖版），正式出图提示词按 绘画-出图.md 问卷流程另跑（设计图/封面归 A 类）。
- **R9 "去 AI 味"诉求→注入终检**：客户提到"别像 AI 写的/过检测" → 按 营销文案.md §4.6 Humanizer 骨架挂第二遍改写块（主动语态、段落≤3短句、句长变速、删 navigate/journey 类套话隐喻、结尾不总结）；"通过 AI 检测工具检测"这类说法一律转写为"自然口语、避免模板腔"（灰色诉求，文案 §5）。
- **R10 版权与署名**：技巧词库/法则结构属社区素材（prompt123/waytoagi 无统一许可，爆款词库署名 DX、Lisp 作品署名李继刚），引擎归纳规则与词表可用、成段原文不搬运；仿爆款只取结构不取词句（营销 §3.5 纪律）。⚠️ 发布后数据反馈→改标题的 A/B 迭代闭环素材缺失。

- **R11 交付形态三选一**：从零创作（Q2=只给主题）→ 完整 Role/规则/Workflow 骨架；扩写·润色（已有草稿）→ §4.5 最小指令式为主，保留原文事实与结构、只加风格清单；批量候选 → 标题 5-10 条或正文 2-3 版供选，各标注所用法则/风格差异，客户选定后定稿。
- **R12 平台词库按渠道切换**：小红书→§3.2 爆款词库随机选 1-2 入标题；公众号→§4.4 结构词（提问引题/案例数据/金句收尾）；英文站点或出海→改走 prompts.chat 单段式"act as + 受众 + first request"，不塞中文平台 emoji 规则（中英文差异，文案 §5）；口播→R6 口语清单。
- **R13 素材质量分层（引擎侧执行）**：优先取带完整方法论/Workflow/Output/few-shots 的条目；prompt123 的"XX 文案专家"空壳（仅 Goals/Skills 泛写，如 1555/930）与 小说 §3.5 空壳只当角色名占位，不可直接当骨架；1170"剧本编剧"名实不符（实为角色配置器），涉编剧需求走 小说与剧本.md 而非它。
- **R14 抓取损伤修正（引擎侧执行）**：引用 prompt123 版 Lisp/长文素材时正文空格与引号可能丢失（`defun一言小说`、弯引号），组装前先做空格/引号归一化或优先 waytoagi 版（小说 §5）；`[ ]` 复选框与模板变量混排处逐字核对。
- **R15 "都行/不懂"兜底**：客户不选时按 小红书笔记 × 只给主题 × 泛人群 × 闺蜜体 × 300-600 字 × 轻度 emoji × 无配图 组装，全部标 `[假设]`，并在终态表念出。

## 终态核对（念给客户确认）

| 槽位 | 值 | 来源 |
|---|---|---|
| genre / platform | 体裁与目标平台 | Q1 |
| topic_material / fact_lock | 主题与素材、是否锁事实 | Q2 |
| audience / tone / length | 读者、语气人设、字数 | Q3-Q5 |
| format（emoji 密度 / 标签数 / 标题党档） | 平台格式规范 | Q6+R5 |
| with_image / titles / opening | 配图、标题候选、开篇法 | Q7-Q9 |
| 路由结果 | 小说→小说骨架 / 带货→营销问卷 / 歌词→音乐问卷 | R2/R4/R3 |
| 注入块 | 去 AI 味终检 / 事实护栏 / 版权替换条款 | R9/R5/R10 |

确认无误 → 走模式 A 组装。

## 终态 → 组装（交回模式 A 第 3-7 步）

1. **正文提示词**：# Role {{平台}}爆款写作专家 → 平台规则块（Q6 换算成显式条款：emoji 密度/标签数/段间空行）→ 技巧参数块（Q4 语气、开篇方法、文本结构；可从 §3.2 词库枚举供模型选或写死）→ Workflow（标题先行 N 个→（可选用户选定）→正文→标签）→ Output 固定格式"一.标题 / 二.正文 / 标签"，只输出格式内内容。
2. 按 Q2 追加：事实保留条款（不确定处标注而非编造）/ 改写式最小指令版。
3. 按 Q7/R8/R9 追加：配图 brief 节、跨问卷出图提示说明、去 AI 味终检块。
4. 备注：所选骨架出处一行（如 文案与自媒体.md §4.1）、假设项标 `[假设]`、若涉在世作家风格模仿只保留风格词不写署名式仿写指令（小说 §5）。
