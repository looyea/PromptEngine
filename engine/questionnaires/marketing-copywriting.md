# 问卷：营销 · 文案（落地页 / 广告 / EDM / 社媒帖 / 电商详情页）

> 用途：引擎模式 B1 的访谈脚本。问完→汇总槽位确认→走模式 A 组装可投放文案提示词（变体即带实验设计）。
> 组装原料：汇总/B2B商业/营销文案.md（§4.1 广告骨架、§4.2 落地页 brief 分离式、§4.3 社媒钩子、§4.4 营销邮件、§4.5 SEO、§4.6 去 AI 味终检、§4.7 爆款拆解改编）、汇总/B2B商业/销售与GTM.md（§4.5 ICP 骨架、§4.1 冷触达——冷邮件归那篇）、引擎/套餐/商城开发.md（详情页路由）。

## 兼容规则表（选择时当场执行，不只体现在选项上）

- **R1 B2B vs B2C 换框架与语料**：B2B——冷静专业、收益导向证据化（数字/案例/风险逆转）、禁 emoji 全大写 buzzwords、钩子偏 好奇×提问/社会证明×反常识、CTA 低摩擦（预约演示）；B2C——情绪与身份认同钩子（FOMO、relatability×第一人称故事）、可 emoji。混用即风格崩（§5 渠道语气冲突）；ICP 决策链多人（Champion/EB）时正文按角色分段说服（销售 §4.5 思想）。
- **R2 医疗/金融/教育品类→合规注入**：Q7 选敏感类 → 在生成规则里追加绝对化用语禁词表（"最/第一/100%/根治/稳赚/无风险"类）、功效与收益表述须留证据、必须含行业免责句（如"投资有风险""效果因人而异"）；⚠️ 本库无成品的文案合规审查提示词（§6：极限词/虚假宣传审查需与 L 类法律拼接），此处注入的是预防性禁则，不替代人工合规审，交付时明示"建议合规人审"。
- **R3 电商详情页→路由**：use_case=详情页 → 若是整套商城建设转 引擎/套餐/商城开发.md（B2 套餐）；若走上架/投放 B 端流程转 销售与GTM.md；只要单页文案 → 用 §4.1 广告骨架×§4.5 关键词嵌入混合组装（标题=利益/痛点、五点描述=具体收益+USP、嵌关键词）；⚠️ 中文平台（淘宝/京东/抖音）详情页字数与敏感词规格素材缺失，按通用电商结构+客户平台规则填写。
- **R4 落地页 brief/指令分离**：use_case=落地页 → 交付分 Part 1（客户填的战略 brief：产品/受众/UVP/唯一目标/品牌语气/上游广告/真实社会证明/竞品/框架/AB 假设）与 Part 2（系统指令）；缺槽位逐个追问，不许模型代填虚构；输出固定 9 段（标题/副标题/主视觉 brief/框架正文+3-5 收益 bullet/社会证明/CTA/表单建议/页脚/UX 提示）。
- **R5 Message Match 联动**：Q1=广告且已有落地页 → 广告文案标题必须与落地页信息一致；落地页副标题承接上游广告——两处任一缺失则先补问。
- **R6 真实性硬条款（不问客户，默认注入）**：社会证明须真实、稀缺紧迫须 genuine——不得编造客户证言/数据/奖项，缺就留 `[待补]` 占位（§5）；素材中的宣称数字（"engagement 300%+""$100M ad spend"）是风格锚不是指标，Success Metrics 只作目标槽并提示客户校准（§5）。
- **R7 变体即实验设计**：Q6≥3 → 广告输出 标题×正文×CTA 组合矩阵、每条标注测试假设；社媒钩子 10 条覆盖五组心理组合矩阵并逐条标注组合（§3.1）；平台规格作硬约束槽（Google 15 标题×30 字符、4 描述×90 字符；LinkedIn 帖默认无 hashtag、连接请求≤300 字符）。
- **R8 默认挂去 AI 味终检**：全部交付默认附 §4.6 第二遍改写块（按 Q5 渠道适配：B2B 禁 emoji/em dash，社媒可保留）；仿爆款走 §4.7"偷结构不偷词句"验收（并排不可被指认为抄袭）。
- **R9 邮件目标分流**：Q1=EDM 且目的=首次冷触达 → 转 销售与GTM.md（冷邮件 ≤75 词、主题 ≤5 词规格在那篇）；nurture/唤醒/行为触发 → §4.4 序列骨架（一封一个 idea，跟进必须新增价值，禁 "checking in"）。
- **R10 平台规格即约束槽（缺项要追问，不默认）**：付费广告必须先定平台（Google / Meta / 信息流），字符上限与条数直接写进生成规则并做超长自检；落地页须给上游广告信息否则 Message Match 无从执行；社媒要先定单平台（LinkedIn 无 hashtag、≤150-200 词；小红书/公众号向的中文排版走 引擎/问卷/写作-自媒体.md 问卷，本问卷只管转化目标与合规）。
- **R11 SEO 分支**：use_case=SEO 长文 → 按 §4.5 产出六件套（关键词+地理变体+同义词簇 / H2-H3 大纲 / 内链机会 / 外链目标清单 / 元标题描述 / 竞品内容差距）并标注优先级与预期影响；此时"框架"题（Q4）改选搜索意图（信息/商业/交易），AIDA 类叙事框架不适用。
- **R12 爆款改编前置**：客户给的是"参考某条爆款帖"而非产品 brief → 走 §4.7 先打分（钩子/互动/结构/可分享/相关度加权，≥3.5 才入库）再提取机制重写；直接让模型"照着写一条"会踩词句搬运，当场拦截。
- **R13 "都行"兜底默认值**：客户全程用默认 → 落地页 × AIDA × MoFu × 专业克制 × 3 变体 × 常规品类，Part 1 仍要求产品一句话与唯一转化目标两项必填（缺了无法保证 message match 与 1:1 注意力比），其余标 `[假设]`。
- **R14 交付后复盘入口（当前能力边界）**：本库素材只到"生成+变体+假设"层，**无投放数据回流→下一轮假设的闭环提示词**（§6 缺口）。客户带着 CTR/CVR 数据回来时，引擎按通用方法论现场搭复盘骨架并明确声明"该领域无专门汇总"，同时建议补采素材；勿用素材里的宣称数字当基准。

## 终态核对（念给客户确认后再组装）

| product_icp / funnel | 产品一句话+ICP+漏斗阶段 | B2B/B2C 分支已判 |

| proof_materials | 真实社会证明清单 | 缺项 `[待补]`，禁虚构 |

| compliance | 禁词表 + 免责句 + 人审提示 | 敏感行业必开 |

客户确认 → 进模式 A 第 3-7 步；改任一槽位即重跑 R1/R2/R5/R6 检查。

## 终态 → 组装（交回模式 A 第 3-7 步）

1. **Part 1 上下文卡（用户填的战略 brief）**：产品一句话 / 受众角色·目标·最大痛点 / UVP / offer / 唯一转化目标 / 品牌语气 / 上游广告信息 / 真实社会证明 1-3 条 / 竞品及卖点 / 真实稀缺元素 / 漏斗阶段 / 叙事框架 / AB 假设——**表单与系统指令解耦**，客户改版复购只改这张卡（§2.3 最值得借鉴的结构）。
2. **Part 2 生成指令**：角色（{{渠道}}资深投放文案/CRO 专家+直复文案，经验锚按 R6 剥离）+ 不可协商原则（1:1 注意力比、Benefit-Oriented、Message Match、可扫读短段+小标题+bullet）+ 心理动线（信任/社会证明/紧迫）+ Q4 框架正文 + 平台硬约束 + 负面清单（禁 buzzword/humble brag/clickbait/"hope this finds you well"）。
3. **输出段**：按 Q1 定段落数——落地页固定 9 段（标题/副标题/主视觉 brief/框架化正文+3-5 收益 bullet/社会证明/CTA 第一人称按钮/表单字段建议/页脚占位/3-4 条 UX 建议）；广告输出变体矩阵（标题×正文×CTA，每条标注测试假设+质量分要点）；EDM 每封给主题行/正文/该触点唯一目标/触发条件与间隔/成功指标。
4. **追加块**：R2 合规禁词与免责（如适用）→ R8 去 AI 味终检 → 1 个 AB 变体并说明差异假设。
5. **备注**：骨架出处一行、宣称数字已剥离、Success Metrics 需客户校准、建议投放前人审（合规+品牌语气）。

## 交付为"生成器"时（B3）

客户想复用时 → 本问卷 + 汇总/提示词方法论/结构化提示词.md §4.2 元提示词骨架合并为"营销文案生成器"提示词（沿用 brief/指令分离结构，客户改版复购只改 Part 1）。
