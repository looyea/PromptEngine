# 文案与自媒体（W）

> 归纳自：素材/web/prompt123（文案/小红书/公众号簇约 60+ 条）、素材/web/waytoagi（市场营销 tag=5 共 29 条）、素材/github/ChatGPT-Shortcut（write/social/company 标签）、素材/github/prompts.chat（Advertiser、Social Media Influencer 等）。
> 定位：平台化内容创作提示词的共性提炼与模板骨架，供引擎按"平台 × 文体 × 风格"组装。营销战略类（投放、SEO、公关）归 B 类，本篇只管"写出来"。

## 1. 概述

素材中的文案类提示词可分四簇：

| 簇 | 典型素材 | 特征 |
|---|---|---|
| 平台爆款文案 | 小红书爆款写作专家、小红书营销大师、爆款文案、公众号文章 | 平台规则显式化：emoji、标签、口语化、标题数量 |
| 标题方法论 | 咪蒙风格标题、娱乐内容标题创作专家、Fancy Title Generator | 把"起标题"拆成法则库（危险/意外/矛盾/痛点/共情） |
| 品牌短文案 | 苹果文案（李继刚 Lisp）、Slogan 生成大师、宣传 slogan | 风格迁移：用修辞规则 + 名作 few-shots 锚定品牌腔 |
| 改写/润色 | 小红书风格改写（AiShort#209）、口播脚本（#204）、文案仿写 | 输入已有文本，输出换风格版本，保持原意 |

质量分层明显：李继刚 Lisp 作品与带完整方法论的 LangGPT 角色（如小红书营销大师）信息密度高；prompt123 大量"XX 文案专家"条目只有 Role/Skills/Goals 空壳（如 1555 公众号文章、930 文案策划），引擎应优先取前者、把空壳仅当角色名占位。

## 2. 共性结构与模式

1. **角色 + 平台规则 + 技巧词库 + 输出格式**四件套。平台规则是中文素材独有增量：每段首尾插 emoji、文末 3-6 个 #SEO 标签、句子口语化短促、段落间空行。
2. **技巧词库枚举化**：把"写作风格/表达语气/开篇方法/文本结构/互动引导/爆款关键词"做成编号清单（小红书营销大师列了 40 种开篇法、60+ 爆款词），既供模型随机抽取，也供用户菜单式选择。
3. **标题先行、批量候选**：几乎都要求先出 5-10 个标题再写正文，标题与正文分离生成；标题类提示词进一步要求"标注所用法则 + 心理触发点分析"。
4. **方法论法则库**：咪蒙五法则（危险/意外/矛盾/痛点/感同身受）每条带子策略与真实例句，是"法则 + few-shots"的教科书式写法；二极管标题法（极端对立词并置）被多篇引用。
5. **风格迁移靠修辞规则 + 名作锚点**：苹果文案把品牌腔拆成 Repetition/Contradiction/Rhyme/short/simple 五个算子，配 5 条苹果官方文案做 few-shots——比"写得像苹果"具体得多。
6. **交互工作流**：菜单选择式（列出全部选项→用户输数字→可跳过→确认后生成）与冷启动开场白（"只有在用户提问时才开始回答"）两种。
7. **英文对照**：prompts.chat 的 Advertiser/Social Media Influencer 是"act as + 任务描述 + first request"单段式，讲 campaign 思维（受众/渠道/关键信息），不含平台排版细节——中文素材恰好补上排版与流量词这一层。

### 3.3 咪蒙风格标题（法则库 + 例句 + 输出分析）
素材/web/prompt123/prompts/10325_咪蒙风格标题.md（https://www.prompt123.cn/sites/10325.html）

```
### 2. 意外法则 (UNEXPECTED)
– 数字法则：使用具体、异常或精确的数字 例：《如何让你的月薪从3000到3万？》
– 符号法则：运用问号、叹号或非常规符号引起注意 例：《你。真。的。不。要。再。熬。夜。了。》
– 反常识法则：挑战常识或价值观，解构固定搭配 例：《谣言止于智者，不止于智障》
### 3. 矛盾法则 (CONTRADICTION)
– 物理矛盾：将对立的物理概念并置 例：《柔软的地方，正发生着坚硬的事》
# Format: 输出10个标题及其分析
1. 生成10个标题，按吸引力和点击率潜力从高到低排序
2. 每个标题后标注使用的主要法则和子策略
3. 为每个标题提供简短说明，解释其吸引力来源和心理触发点
## 待生成标题的内容：{{content}}
```

### 3.4 苹果文案（李继刚 Lisp：修辞算子 + 官方文案 few-shots）
素材/web/prompt123/prompts/1051_苹果文案.md（https://www.prompt123.cn/sites/1051.html）

```
(defun 苹果御用文案师 ()
  (list (技能 . (精准 修辞 创意))
        (信念 . (极简主义 优雅 价值))
        (表达 . (简练 韵律 矛盾往返))))
(defun 苹果文案 (用户输入)
  (let* ((响应 (-> 用户输入 分析价值点 Repetition Contradiction Rhyme short simple)))
    (few-shots (("iPhone11Pro" "Pro cameras. Pro display. Pro performance.")
                ("iPhoneSE" "Lots to love. Less to spend.")
                ("AppleWatchSE" "Heavy on features. Light on price.")))
    (SVG-Card 用户输入 响应)))
```

## 5. 差异与注意点

- **中英文差异**：英文素材（prompts.chat、AiShort 英文正文）重"任务与受众"（campaign、target audience），一段式 + first request 冷启动；中文素材重"平台排版与流量词"（emoji 密度、标签数、爆款词库），并发展出菜单交互与法则库。AiShort 的 zh 字段多为"中文标题 + 英文正文 + Respond in Chinese"，组装时注意语言指令一致性。
- **版权逐条看来源**：prompts.chat 为 CC0（仓库历史声明）；ChatGPT-Shortcut 为 MIT；waytoagi 与 prompt123 无统一许可证，版权归原作者（小红书营销大师署名 DX，苹果文案/爆款词库相关 Lisp 作品署名李继刚），各素材文件头部保留来源 URL，商用需回溯授权。
- **内容风险**：咪蒙法则库原例句含低俗/擦边标题（欲望痛点类），引擎入库时应替换例句、保留法则结构；"通过 AI 内容检测工具检测"这类约束属灰色诉求，建议改写为"自然口语、避免模板腔"；恐吓式标题需加"不得虚构事实"护栏。
- **质量分层**：prompt123 的"XX 文案专家"空壳条目（仅 Goals/Skills 泛写）信息量低，不要与完整方法论条目同权重使用。

## 6. 缺口

- 视频号/B站/微博/抖音图文的平台细则条目少（短视频仅有脚本类，见《小说与剧本》）；缺各平台字数/话题机制的硬约束表。
- 缺"数据反馈→迭代"闭环提示词（发布后复盘、A/B 标题测试）；小红书博主账号拆解专家（894）是苗头但未精读入库。
- 品牌 tone-of-voice 定制（企业自有语料 few-shots）无现成素材，需引擎侧自建词库槽位。
- 设计图/封面类（小红书封面、公众号头图）归 A 类，见 汇总/AI绘画动漫/ 相关文档，此处不重复。
- 营销战略、SEO、电邮营销（waytoagi 300/308）归 B 类待写文档，本篇仅交叉引用。
