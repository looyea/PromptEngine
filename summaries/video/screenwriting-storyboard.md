# 剧作与分镜（场景公式 · Murch 六原则 · 分镜卡 → 视频提示词）

> 一级类：V 影视/视频生成 · 二级：叙事/剧本 + 美术
> 素材：`素材/github/visual-skills/video/references/dramaturgy.md`、`animatic-keyframes.md`、`patterns-and-genres.md`、`fixes-and-skeletons.md`（CC-BY-4.0，需署名 Serge Shima / smixs/visual-skills）；`素材/github/lanshu-awesome-ai-video-kit/methodology/03-分镜时序.md`、`04-情绪外化表.md`（MIT）
> 用途：引擎在写视频提示词**之前**的剧作层骨架——把"想法"变成有戏剧功能的分镜，再逐镜转化为平台提示词（转化目标见《视频生成提示词.md》§4）。

## 1. 概述

visual-skills 的核心主张：**剧作是强制层，语法是可选层**。"没有剧作的美丽画面是壁纸（wallpaper）"；每条提示词发出前必须过剧作检查。方法论链条：

```
场景公式（这场戏为什么存在）
→ 五锚点（情绪/母题/锚物/断裂/终帧）
→ 三层分镜（戏剧节拍 → 镜头功能 → 剪辑节奏）
→ 14 字段分镜卡（每镜填满，空字段=缺导演意图）
→ 平台提示词（《视频生成提示词.md》§4 骨架）
→ 六项剧作审计（通过才交付）
```

lanshu 的中文分镜时序（镜头1/2/3 按事件顺序、每镜四维度）与情绪外化表（抽象情绪→身体细节速查）是同一思想在中文平台的落地，两者可直接对接。静态关键帧（animatic）另有专用卡片与"运动残留"画法，衔接 A 类《构图与分镜.md》的静态构图方法。

## 2. 共性结构与模式

### 2.1 场景公式（核心律）

```text
场景 = 主角此刻的欲望 + 障碍 + 空间几何 + 受控视线 + 剪辑节奏
```
五要素缺一即塌成装饰。写 prompt 前每项用一句话命名：欲望（这一秒想要什么）、障碍（物/人/恐惧/距离/规则）、几何（谁站哪、谁占权力位、威胁与逃生方向）、视线（每帧一个焦点，观众被迫看哪）、节奏（每镜活多久、停顿落哪、剪切咬在哪）。命名不出=场景没想好。

### 2.2 三细节法则与镜头三职责

- **三细节**（每镜必带，最常被违反的规则）：1 环境压力（冷冰箱光/湿沥青/闪烁灯管/壶口蒸汽）+ 1 身体微动作（下颌锁紧/指节发白/用力吞咽）+ 1 声音锚或视觉母题（重复的胃鸣/每次转场的玻璃倒影）。零细节=填充镜头，删或重写；"定场镜头/产品英雄镜头"恰恰是最先偷懒的重灾区。
- **三职责**（每镜至少干一件事，否则删）：改变情绪 / 推进动作 / 增加压力。"美丽的定场镜头"不是职责。
- **禁词表**：cinematic、epic、stunning、masterpiece、beautiful lighting、dynamic camera、intense moment、"he is sad"——每个都是缺席细节的占位符。

### 2.3 Walter Murch 剪辑六原则（Rule of Six）

决定在哪里剪的优先级，**每项权重高于其下所有项之和**（《现代启示录》《教父2》剪辑师经验值）：

| 优先级 | 原则 | 权重 | 检验问题 |
|---|---|---|---|
| 1 | 情感 Emotion | 51% | 这一剪是否忠实于此刻的情绪真相？观众现在感受到什么、下一步该感受什么？ |
| 2 | 故事 Story | 23% | 是否推进故事或揭示角色？ |
| 3 | 节奏 Rhythm | 10% | 是否落在场景的音乐性节拍上？ |
| 4 | 视线追踪 Eye-trace | 7% | 剪切瞬间观众视线在哪？新镜头是否自然接住？ |
| 5 | 二维平面 2D plane | 5% | 是否尊重银幕方向轴线？ |
| 6 | 三维空间 3D space | 4% | 是否尊重真实场地几何？ |

实践推论：为"动态"而剪只排在第 3 位；不服务 1、2 的快剪是注意力缺陷式广告。

### 2.4 场面调度与镜头动机

- **Blocking=欲望的编舞**：不是"演员站哪"，而是"角色想要什么、向谁移动、避开谁、把谁逼到角落、向谁让出空间"。坏："他站在窗边"；好："他挪向窗户，但肩膀仍朝向她，仿佛对话还拽着他"。
- **Staging 先于台词陈述冲突**（权力信号）：站者压坐者；门口者控制房间；玻璃/倒影后者心理疏远；阴影者带威胁或悲伤；负空间=孤立；紧框=窒息；同框无对视=亲密破裂。
- **镜头必须有理由**（Fincher 规则）：每次运动回答"什么变了？"——决定做出/新信息入画/压力升级/角色看向某处/空间改变。答不出就固定机位。坏："cinematic gliding movement"；好："推镜始于'I don't know'，止于她下颌锁紧"。
- **空间清晰高于蒙太奇狂热**（Spielberg 原则）：再快也要知道主角在哪、威胁在哪、逃生与决策方向。快剪序列先用一句话画地理："主角左→右移动，威胁从画顶进入，出口在画右外"。
- **环境会演戏**（黑泽明原则）：每场选一个环境压力承载情绪——闪烁荧光=衰败/官僚/恐惧；窗上雨=压抑的悲伤；壶口蒸汽=压住的怒；湿夜沥青=负罪；镜面=自我审判。

### 2.5 三层分镜法与节奏阶梯

- **层 1 戏剧节拍**（60-90s 可靠节拍图）：0-5s Hook（主角已在张力中，无铺垫）→ 5-15s Context → 15-30s Pressure（试图维持控制）→ 30-45s **Crack**（一个细节击穿主角立场）→ 45-60s Acceleration（镜头变短呼吸变紧）→ 60-75s **Impact**（决定/破裂/告白/行动）→ 75-90s Aftermath（短暂沉默或视觉残留）。30s/15s 按比例压缩，**Crack 与 Impact 永不跳过**。
- **层 2 镜头功能**（九标签）：Establish 定场 / Power 权力 / Pressure 压力 / Detail 细节锚 / Reaction 反应 / Shift 内在变化外显 / Impact 决定性一帧 / Aftermath 余波 / Exit 终帧。
- **层 3 剪辑节奏**：阶梯而非匀速——`长- shorter - shorter - pause - impact`。**最大剪切前的停顿比剪速更重要**，没有停顿的速度是视觉绞肉机。
- **节奏阶梯四型**：慢热剧 4s,4s,3s,2s,1s,pause,2s；商业产品弧 3s,2s,1.5s,1s,0.5s(产品微距),2s(英雄镜头)；焦虑累积 2s,1s,1s,0.5s,0.5s,0.3s,pause,1s；冲击场 pause,0.2s(闪),2s(静止余波)。

### 2.6 五锚点原则

任何短剧只承诺五个锚，不多：**一个主情绪 + 一个视觉母题 + 一个锚物 + 一个断裂 + 一个终帧**。例（负罪感）：母题=玻璃倒影反复出现；锚物=一条未读消息的手机；断裂=他删除消息；终帧=他的脸映在黑掉的手机屏上。

### 2.7 中文分镜时序与情绪外化（lanshu）

- 每镜按四维度组织：**运镜/切换方式 + 主体动作表情 + 位置空间变化 + 音频信息**；用"镜头1/2/3"按事件顺序（先主后次），不强制秒数（Seedance 对精确时间支持不稳定）。
- 情绪外化：模型看不懂"很悲伤"，写身体——悲伤=低头/肩微颤/攥衣角/眼眶泛红泪不落；愤怒=双拳紧握/下颌紧绷/胸口起伏/牙缝挤话；犹豫=张嘴又闭/视线游移/手悬半空。**每镜只写 1-2 个关键动作**，多了稀释焦点（与 U3 的 2-4 线索校准一致）。
- 长叙事策略：文戏（长对话/情绪递进）用视频延长一镜到底；武戏/转折（追逐/打斗/蒙太奇）分段生成再剪辑。

### 2.8 静态关键帧（animatic）特有模式

面板是单位而非镜头：一张静止图必须同时承载**一个可读节拍 + 一个功能标签 + 一个情绪 + 一个隐含运动**。核心纪律："不能把'运动'或'情绪'prompt 进静帧——只能 prompt 它们留下的物理后果"。
- **六种冻结运动线索**：方向性动态模糊拖影（背景拉丝主体锐利）/ 局部冻结模糊（胎壁褶皱、换挡手）/ 整幅 streak 帧（暗示 whip pan）/ 姿态 trajectory 矢量（只能向前解决的姿势）/ 锐主体-糊背景分离（微距插入）/ 刻意零模糊的静止帧（停钟感）。
- **速度预算**：一帧至少 3/5 共存才卖速度——低机位、下半幅沥青拉丝、近前景参照物掠边、锐主体糊背景、机械振动线索（颤镜/双影指针）。
- **无脸情绪**：决策→动作中的解剖（手必须在做动词：grip/latch/shift/release，无动词无面板）；内在状态→跨阈值后的物件（转速表钉在红区而非怠速）；注视/对抗→空间。
- **密度阶梯**：安静仪式=1 幅持 2s；压力爬升=3 幅递减；爆发=6-9 幅微连击（8fr→4fr）；爆发之间必插一幅安静持帧；余波=1-2 幅持帧。30s 约 18-26 幅。

## 3. 代表样本

**样本 1：五锚点 + 节拍图（负罪感 30s）**（`素材/github/visual-skills/video/references/dramaturgy.md` §14，节选）
```text
锚点：情绪=负罪；母题=玻璃倒影；锚物=未读消息手机；断裂=删除；终帧=黑屏上的脸。
0-3s   Hook：手机在暗桌上震动，脸被下方光照亮。
3-10s  Context：加班后的小办公室，空工位，冷荧光，显示器里的倒影。
10-18s Pressure：盯着消息预览，下颌收紧，手悬停。
18-22s Crack：开始打字，停下，逐字删除。
22-26s Acceleration：紧剪——手指/屏幕/眼睛/呼吸/窗倒影。
26-28s Impact：taps Delete Conversation。一下。沉默。
28-30s Aftermath：屏幕黑掉，他的脸仍映在暗玻璃上。
```

## 4. 可复用模板骨架（引擎原料）

### 4.1 导演概念卡（写任何 prompt 之前，Format E）

```text
核心想法：{{一句话}}
情绪弧：{{状态1}} → {{状态2}} → {{状态3}}
视觉母题：{{一个反复出现的元素}}
节奏逻辑：{{慢热/焦虑累积/冲击/产品弧}}
镜头语法：{{主导运镜与景别策略}}
主光源：{{一个有动机的光源+方向}}
声音质地：{{环境压力声/母题声}}
终帧：{{观众带走的最后一幅画面}}
```

### 4.2 场景就绪检查（五要素命名）

```text
欲望：{{角色这一秒想要什么}}
障碍：{{什么挡住他（物/人/恐惧/距离/规则）}}
空间几何：{{谁站哪；权力位；威胁方向；逃生方向}}
受控视线：{{每帧唯一焦点是什么}}
剪辑节奏：{{每镜时长；停顿落点；剪切咬点}}
→ 任一项命名不出：回到 4.1，场景未就绪，不进入分镜。
```

### 4.3 三层分镜生成骨架

```text
输入：{{时长 T}} + {{概念卡}} + {{五锚点}}
层1 节拍图（按 T 压缩 2.5 的 60-90s 模板；Crack/Impact 必保）：
  Hook {{0-a}} / Context {{a-b}} / Pressure {{b-c}} / Crack {{c-d}}
  / Acceleration {{d-e}} / Impact {{e-f}} / Aftermath {{f-T}}
层2 逐镜功能标签：每镜从 Establish/Power/Pressure/Detail/Reaction/Shift/Impact/Aftermath/Exit 选一
层3 节奏：选 2.5 阶梯一型，最大剪前插停顿；输出每镜 Duration
输出：分镜表（格式 C：Time|Shot|Function|Action|Camera|Light|Sound|Emotion）
```

### 4.4 分镜卡 → 视频提示词转化流程（本篇核心交付）

```text
对每张分镜卡执行字段映射：
  Emotion        → 身体微动作 2-4 个（查 4.6 外化表；禁写情绪名）
  Beat+Action    → 主动词短语 + 物理后果（U9）
  Composition+Eye trace → 构图/焦点句（每帧一个焦点）
  Camera+Movement reason → 单一运镜+焦段；无理由则 "locked static frame"
  Light/color    → 具体光源+方向+色温（跨条逐字重复）
  Sound          → 平台音频块（Veo Audio:/Says:；Kling Audio.；Seedance ()<>{}）
  Duration       → Kling 3.0 写 Shot n (ts)；Seedance 写 镜头N 不写秒；Sora 式写 beat
  Cut type       → 多镜标记（Shot n / Cut to. / 镜头N）+ 相邻镜景别角度必不同
  Production note → 连续性块（preserve X）与参考素材角色声明（U13）
每镜组装进《视频生成提示词.md》§4.1 通用骨架或对应平台骨架；
多镜序列：身份块每条重复（U7），终帧卡 → 最后一条的结尾句（U11）。
转化后跑 4.7 审计，未过不发。
```

### 4.5 关键帧卡 → 图像提示词骨架（animatic 路线）

```text
{{景别+焦段}} still, {{主体=唯一视线锚}}.
前景 {{职责：框住/遮挡/代入}}；中景 {{主体+动作瞬间}}；背景 {{stakes/语境}}.
Motion-as-still: {{六冻结线索之一，如"主体锐利+背景沿运动轴拉丝"}}.
Emotion-via-object: {{物件跨阈值后的状态}}.
{{单一动机光源+方向+被照表面}}；palette {{具体颜色}}.
{{画幅}}；no face（如适用）；implied camera: {{这张图是哪个运动的第一帧}}.
→ 图像平台语法参考 A 类《构图与分镜.md》；锁定后的关键帧再作图生视频首帧
  （《视频生成提示词.md》§4.8），实现"静帧锁构图 → 视频赋运动"两段流水线。
```

### 4.6 情绪外化查询骨架

```text
输入：{{抽象情绪}} + {{场景语境}}
输出：2-4 个可观察身体线索（眼/眉/嘴/呼吸/喉/手），每镜只用 1-2 个关键动作
速查（lanshu 04）：悲伤→低头肩颤攥衣角；喜悦→嘴角上扬脚步轻快；
紧张→看表敲桌呼吸急促；愤怒→握拳下颌紧绷胸口起伏；释然→长舒气肩放松淡笑远望；
恐惧→瞳孔放大退半步抓物屏息；疲惫→揉太阳穴靠墙眼皮沉；专注→眉微皱眼锁定身前倾；
犹豫→张嘴又闭视线游移手悬空；惊喜→眼睁大嘴O形捂嘴笑容缓绽。
```

### 4.7 发送前六项剧作审计（质检门原料）

```text
[ ] 场景公式五要素齐全？
[ ] 每镜过三细节检查（环境压力+微动作+声音/母题锚）？——最常违反
[ ] 每镜至少干一件职责（改情绪/推动作/增压力）？
[ ] 每次运镜有动机（回答"什么变了"）？
[ ] 空间几何可读（主角/威胁/逃生/决策方向）？
[ ] 五锚点已命名（情绪/母题/锚物/断裂/终帧）？
```

## 5. 差异与注意点

- **许可证**：visual-skills CC-BY-4.0，方法论改写/引用须署名（Serge Shima, github.com/smixs/visual-skills）；lanshu MIT。Murch 权重（51/23/10/7/5/4）是剪辑师经验表述，用作优先级排序即可，不必当精确科学。
- **时码口径**：分镜卡/分镜表层用 timecode 做设计没问题；落到 Seedance prompt 层去掉精确秒数（官方：强行限时可能异常），Kling 3.0 反而必须写时码。设计与生成两层口径分离。
- **与 A 类《构图与分镜.md》分工**：那篇管静态插画/漫画分格（NAI v5 技能链、格形容纳镜头）；本篇管时间性镜头与剪辑节奏。关键帧（animatic）是两者交接口：静帧构图用 A 类方法，节拍/功能/节奏用本篇。
- **每镜线索数**：lanshu 说"每镜 1-2 个关键动作"，visual-skills 说"一次情绪转变 2-4 个线索"——前者指动作事件数，后者指微表情线索数，不矛盾；组装时动作事件 1 个+身体线索 2-4 个。
- 空词禁令与 SD/NAI 图像玩法相反：图像模型吃 masterpiece/质量标签，视频模型惩罚它们。跨域组装（先图后视频）时图像 prompt 的质量词不要带进视频 prompt。
- patterns-and-genres.md 提供 6 种蒙太奇模式（Escalation/Anxiety/Discovery/Catastrophe/产品剧/MV loop）与 8 个类型模块，节拍图假设因果 spine；无对手戏/单高潮/开放结局先选弧再铺节拍。
